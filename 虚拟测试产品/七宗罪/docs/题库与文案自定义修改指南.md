# 题库与文案自定义修改指南 (支持二次开发与品牌替换)

本项目采用高度模块化的代码架构，所有题目、选项权重、报告文案均与页面逻辑完全解耦。你可以非常轻松地修改题目，甚至改造成其他类型的心理/性格测验（如 MBTI 暗黑版、九型人格、精神动物等）。

---

## 1. 如何修改或新增测试题目

打开文件：[`assets/js/questions.js`](file:///d:/虚拟测试产品/七宗罪/assets/js/questions.js)

找到 `QUESTIONS` 数组，每道题的结构如下：

```javascript
{
    id: 1,
    title: "题目描述内容……",
    options: [
        { text: "选项A文字描述", weights: { sloth: 4, wrath: 1 } },
        { text: "选项B文字描述", weights: { wrath: 4, pride: 1 } },
        { text: "选项C文字描述", weights: { gluttony: 4, sloth: 1 } },
        { text: "选项D文字描述", weights: { greed: 4, pride: 1 } }
    ]
}
```

* **修改方法**：直接用文本编辑器修改 `title` 与 `options[].text` 中的文字即可。
* **维度权重**：`weights` 中的键名对应 7 宗罪的代号：
  * `pride`: 傲慢
  * `envy`: 嫉妒
  * `wrath`: 暴怒
  * `sloth`: 懒惰
  * `greed`: 贪婪
  * `gluttony`: 暴食
  * `lust`: 色欲

## 2. 如何修改深度分析报告文案

打开文件：[`assets/js/reports.js`](file:///d:/虚拟测试产品/七宗罪/assets/js/reports.js)

找到 `REPORTS_DATA` 对象，每个罪名都包含了极其详尽的字段：

* `archetype`: 角色暗黑称号（如 `清醒的孤傲者`）
* `coreMotto`: 专属仪式感金句
* `coreAnalysis`: 潜意识深度心理学溯源长文
* `behaviorTraits`: 职场、社交、亲密关系三个场景的投射
* `triggerPoints`: 暗面爆发诱发点
* `lightGift`: 隐藏超能力与光明面转化
* `soulChemistry`: 天生契合与相克罪印人格
* `healingAdvice`: 心理自愈与调适指南

直接修改其中的中文文案，保存即可在前台实时生效。

## 3. 如何修改通用免密/特权卡密

打开文件：[`assets/js/license.js`](file:///d:/虚拟测试产品/七宗罪/assets/js/license.js)

找到 `DEFAULT_CONFIG` 对象中的 `masterKeys` 数组：

```javascript
masterKeys: ['VIP888', 'SIN2026', 'DARK666', 'LUCIFER99']
```

你可以随意添加你专属的公众号口令（例如 `MYWX666`），用户输入该口令也能直接通过校验。
