# 小白一键部署与上线指南 (零服务器成本上线)

本程序采用纯静态现代化架构设计，**不需要租用昂贵的云服务器，不需要安装复杂的数据库**，以下为你提供 3 种完全免费、3 分钟即可拥有专属公网域名的上线方案：

---

## 方案一：使用 Vercel 免费上线（最推荐，速度快且全球CDN）

1. **注册账号**：
   * 打开 [Vercel 官网 (vercel.com)](https://vercel.com)，使用 GitHub 或邮箱免费注册并登录。
2. **上传项目**：
   * 方式 A（直接拖拽）：在 Vercel 控制台点击 **Add New...** -> **Project**，选择直接上传本地项目文件夹。
   * 方式 B（通过 GitHub）：将本项目代码上传到你的 GitHub 私有/公开仓库，在 Vercel 中点击 **Import** 导入该仓库。
3. **完成部署**：
   * 点击 **Deploy** 按钮，等待约 10 秒钟，系统就会自动生成一个专属的公网链接（如 `https://seven-sins-quiz.vercel.app`）。
   * 手机、小红书、微信均可直接点击打开！

---

## 方案二：使用 Cloudflare Pages 上线（永久免费，国内访问稳定）

1. 登录 [Cloudflare 官网 (cloudflare.com)](https://dash.cloudflare.com/)。
2. 在左侧菜单点击 **Workers 和 Pages** -> **创建应用程序** -> 选择 **Pages**。
3. 选择 **直接上传资产 (Upload assets)**，将本文件夹中的所有文件打包拖拽上传。
4. 命名项目后点击 **部署站点**，即可获得类似 `https://seven-sins.pages.dev` 的永久免费访问网址。

---

## 方案三：已有宝塔面板 / 云服务器的上线方法

如果你自己已有阿里云/腾讯云服务器和宝塔面板：

1. 登录宝塔面板 -> 点击左侧 **网站** -> **添加站点**。
2. 输入你的域名（如 `test.yourdomain.com`），PHP版本选择“纯静态”。
3. 进入该站点的根目录，把本项目的所有文件（`index.html`, `admin.html`, `assets/`, `docs/`）直接上传解压到根目录下。
4. 在宝塔面板中为域名申请免费的 SSL 证书（开启 HTTPS），即可正常访问。

---

## 🔒 管理后台安全建议

* 部署上线后，管理后台访问地址为：`https://你的域名/admin.html`。
* 默认管理员密码为：`admin888`。
* 若需修改管理员密码，直接用记事本打开 `admin.html`，找到第 163 行：
  ```javascript
  const ADMIN_PASS = 'admin888'; // 改为你自己的强密码
  ```
  保存重新上传即可。
